# Shared KB

Owns Barry shared/community solutions KB behavior, including anonymized lesson schemas, static snapshot building, manifest signatures, search over generated shared KB indexes, Cloudflare-oriented publishing docs, local opt-in contribution modes, and trust-state rules for reviewed and trusted community lessons.

Use this pack for changes to `barry-cache kb`, shared KB JSONL validation, signed manifests, shared KB search, shared KB contribution settings, revocation handling, or shared solutions KB publishing docs.
