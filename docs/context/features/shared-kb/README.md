# Shared KB

Owns Barry shared/community solutions KB behavior, including anonymized lesson schemas, static snapshot building, manifest signatures, search over generated shared KB indexes, vendor-neutral distribution docs, local opt-in contribution modes, trust-state rules for reviewed and trusted community lessons, and the self-hostable Brain server that ingests submissions, serves the vendor-neutral KB contract, and produces signed snapshots for private (company) or global deployments.

Use this pack for changes to `barry-cache kb`, shared KB JSONL validation, signed manifests, shared KB search, shared KB contribution settings, revocation handling, shared solutions KB publishing docs, or the Brain server under `brain/` (HTTP contract, SQLite store, identity/fingerprint, trust policy, conformance suite, Docker packaging).
